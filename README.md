## 資料夾內容

|---|---|

| `games/` | 所有遊戲 |
| `LICENSE` | 授權聲明 |
| `README.md` | 這份說明 |

## 第一次上傳到 GitHub Pages

### 用電腦

1. 登入 github.com，右上角「+」→「New repository」，名稱例如 `games`，選 **Public**，按「Create repository」。
2. 點「uploading an existing file」，把資料夾**裡面的所有檔案和資料夾**拖進去（不是拖資料夾本身），按「Commit changes」。
3. 到「Settings」→「Pages」，Source 選「Deploy from a branch」，Branch 選 `main`、資料夾選 `/ (root)`，按「Save」。
4. 等一到兩分鐘，Pages 頁面上方會出現網址，例如 `https://你的帳號.github.io/games/`。

### 用 iPhone

GitHub App 可以建立 repository、修改文字檔，但不能上傳檔案，也不能開 Pages，這兩件事要用 Safari。

1. 在「檔案」App 點壓縮檔，自動解壓縮。
2. 用 Safari 打開 github.com，點網址列左邊的「大小」圖示，選「要求桌面版網站」。
3. 手機一次只能選檔案、不能選資料夾，所以要分三次上傳：
   - **最外層**：點「uploading an existing file」，多選所有最外層的檔案，按「Commit changes」。
   - **games 資料夾**：「Add file」→「Create new file」，檔名輸入 `games/a.txt`，內容隨便打一個字，Commit。再點進 `games` →「Add file」→「Upload files」，多選所有遊戲檔，Commit。
   - **icons 資料夾**：用同樣的方法建立 `icons/a.txt`，再把圖示傳進去。
4. 「Settings」→「Pages」照電腦版第 3 步設定。

> 免費帳號的 GitHub Pages 必須是 Public，代表程式碼別人看得到。玩家的存檔不會上傳，只存在他們自己的裝置裡。

## 更版（每次更新都照這三步）

1. 換掉或修改要更新的檔案。上傳時同名檔案會直接覆蓋。
2. 打開 `config.js`：
   - 把 `version` 改成新號碼，例如 `'1.2.1'` → `'1.2.2'`。
   - 在 `changelog` 最上面加一筆：`{ v: '1.2.2', date: '2026-11-01', notes: ['修正了什麼', '新增了什麼'] },`
3. 上傳改過的檔案，按「Commit changes」。

玩家下次打開合集，上方會出現「有新版本可以更新」，點一下就完成，存檔不受影響，接著還會顯示這次的更新內容。

> **一定要改 version。** 沒改的話，已經安裝成 App 的玩家會一直用到舊版。

### 更新紀錄會自動整理

`config.js` 的 `changelog` 只要一直在最上面加新的一筆就好。玩家在「關於與更新」→「更新紀錄」看到的是依系列分組的清單（例如 v1.5 系列、v1.4 系列），只有最新一組展開，舊的自動收合，所以不用擔心越寫越長。每次更新後跳出的提示，也只會顯示最近兩次更新。

### 小改動直接在網頁或 App 改

在 GitHub 點開檔案 → 鉛筆圖示（App 是右上角選單的「Edit File」）→ 修改 →「Commit changes」。改完一樣要記得改 `config.js` 的版本號。

### 查看或還原舊版本

repository 的「Commits」會列出每一次上傳，點進去可以看改了什麼。要還原時，把舊版檔案下載下來再上傳一次即可。

## 修改作者、年份與標題

都在 `config.js` 最上面：

```js
title: '小遊戲合集',
author: 'hua',
year: 2026,
```

首頁底部會顯示「© 年份 作者　版權所有　版本號」。如果要改成每年自動更新年份，把 `year` 那行刪掉即可。

## 音效

全部遊戲共用一個音效開關，存在這台裝置上：每款遊戲上方返回列的喇叭按鈕，或首頁「關於與更新」裡的「遊戲音效」。音效都是用程式即時合成，不用另外放音檔。

- 共用的聲音（按按鈕、成功、失誤、過關、成就）寫在 `gc.js` 的 `SFX` 清單裡。
- 遊戲裡要加專屬音效，呼叫 `GC.sfx('名稱')` 即可，例如 `GC.sfx('coin')`。
- iPhone 的實體靜音開關打開時，網頁可能不會有聲音。

## 成就、每日挑戰與等級

每位玩家各自累積，會跟著存檔一起匯出匯入，換裝置不會消失。

- **玩家等級**：玩遊戲、解鎖成就、完成挑戰都會得到經驗值（XP），升級會有新稱號：新手店員 → 見習廚師 → 小店老闆 → 街頭人氣王 → 人氣主廚 → 美食達人 → 名店店長 → 傳說店長。
- **每日挑戰**：每天依日期從清單抽三個不同遊戲的小任務，同一天所有玩家抽到的一樣。每個 30 XP，三個全完成再加 60 XP。
- **成就**：每款遊戲各有數個，另有連續遊玩等綜合成就，目前共 98 個。紅色的是進階成就，經驗值較多。
- **通知**：在遊戲裡解鎖成就或完成挑戰時，畫面上方會跳出提示。
- **首頁**：顯示等級、今日挑戰進度和成就清單。

### 任務或成就沒有被偵測到

1. 打開首頁「關於與更新」，看「成績回報檢查」。玩過一局之後，那款遊戲應該會顯示最後回報時間；如果是「還沒收到」，代表那個遊戲檔還是舊版，重新上傳 `games/` 裡的遊戲檔即可。
2. 在遊戲裡解鎖成就時，畫面上方會跳出金框通知。完全沒有通知，也是遊戲檔沒更新。
3. 成績是在「結算畫面」出現時才記錄，中途離開不算。
4. 每日挑戰的「舒芙蕾」指的是獨立的舒芙蕾遊戲，三味廚房裡的舒芙蕾不算。
5. 已安裝成 App 的玩家，要先在首頁點「更新」，新的遊戲檔才會生效。

## 共用幣、收藏商店與限時活動

- **共用幣**：成就、每日挑戰、全勤、玩完一局（每天最多 30 幣）都會得到幣，全部遊戲共用。首頁等級那一行的「●」就是目前的幣，點下去開收藏商店。
- **收藏商店**：花幣買杯緣色（拉一杯花、一杯好咖啡的杯子）、毛孩配件（毛孩小屋）、農場裝飾（小菜園）和稱號（顯示在首頁）。買了會自動套用到遊戲裡。
- **限時主題活動**：依日期自動開啟，活動期間賺到的幣 ×1.5，累計完成 10 局、25 局可以領獎勵，限時商品也只在這段時間可以買（買過的永遠保留）。目前內建：萬聖夜祭（10/24–11/1）、聖誕市集（12/18–12/28）、跨年煙火（12/29–1/3）、櫻花祭（3/20–3/31）、夏日冰飲祭（7/15–8/15），以及只有 2027 年日期的春節（2/3–2/14）和中秋（9/10–9/18）。

### 修改商品和活動

都在 `gc.js` 裡：`COLL` 是商品清單，`THEMES` 是活動清單。每年固定的活動寫 `m: [開始月, 開始日, 結束月, 結束日]`；農曆節日每年日期不同，要寫 `abs: ['2027-02-03', '2027-02-14']`，**過了要記得更新下一年的日期**。新增商品時，如果要在遊戲裡顯示，遊戲那邊也要有對應的畫法。

### 修改或新增成就、每日挑戰

打開 `gc.js`，最上面有兩份清單：

- `A('id', '遊戲 id', '名稱', '說明', 條件, 是否進階)`：一行就是一個成就。條件例如 `['max', 'bubble-tea', 'money', 500]` 代表搖搖茶舖的營業額曾達到 500。
- `QUESTS`：每日挑戰清單，`type: 'max'` 是單次達到，`'sum'` 是今天累計。

改完記得改 `config.js` 的版本號。**新增成就時，舊玩家過去的紀錄不會回頭計算**，要之後再玩才會累積。

### 讓遊戲回報成績

遊戲在結算的地方呼叫下面三個函式，沒有載入 `gc.js` 的環境也不會出錯（前面加 `window.GC&&`）：

```js
GC.report('遊戲id', { score: 85, money: 500 });  // 一局結束：次數 +1，並記錄各項成績
GC.max('遊戲id', { bond: 5 });                    // 只記錄最高紀錄，不增加次數（常駐型遊戲）
GC.add('遊戲id', 'fed', 1);                       // 累加數量，例如餵食次數
```

指標名稱可以自己取，只要和 `gc.js` 清單裡寫的一樣就會被計算。

## 新增一款遊戲

1. 遊戲的 html 放進 `games/`。
2. 在該 html 的 `</head>` 前加一行：`<script src="../gc.js"></script>`
3. 把遊戲裡的 `localStorage.getItem / setItem / removeItem`，全部改成 `GCStore.getItem / setItem / removeItem`，存檔才會分玩家存放。
4. 想讓它有成就和每日挑戰：在結算處加上 `GC.report(...)`，並在 `gc.js` 加入對應的成就（見上一節）。
5. 在 `config.js` 的 `games` 清單加一筆（id、file、name、desc、icon、color、tags、kw），並改版本號。
   - `tags` 是這款遊戲的分類，可以填一個或多個，例如 `tags: ['手作', '經營']`。目前的分類是：手作、經營、策略、養成。
   - 首頁的分類按鈕是一排平分寬度，**建議最多 5 個**（含「全部」會是 6 顆），再多就會擠不下。要新增分類時，加進 `categories`。
   - `kw` 是額外的搜尋關鍵字（選填），把細項的類型和玩法寫在這裡，例如 `kw: ['咖啡', '拿鐵', '拉花']`。玩家搜尋這些字也找得到這款遊戲，但不會佔用分類按鈕的位置。

## 玩家說明（可以直接轉傳）

- **iPhone**：用 Safari 打開網址（在 LINE 裡請點右上角選「用 Safari 開啟」）→ 點分享 →「加入主畫面」，之後都從主畫面圖示打開。從 Safari 和從圖示打開是兩份不同的存檔。
- **Windows**：用 Edge 或 Chrome 打開，點網址列右側的「安裝」圖示。
- **找遊戲**：首頁上方有搜尋框，可以搜名稱、說明或玩法；下面一排分類按鈕（手作、經營、策略、養成）可以篩選。遊戲以清單呈現，右側的「玩過」標籤代表這位玩家玩過。
- **多個玩家**：首頁右上角點名字，可以新增、切換、改名、刪除玩家。
- **換裝置**：在舊裝置的「備份與轉移」按「匯出存檔檔案」或「複製轉移碼」，用訊息傳到新裝置；在新裝置的「備份與轉移」選擇存檔檔案，或按「貼上」再按「匯入」。可以選擇新增成新玩家，或覆蓋目前的玩家。
  - 轉移碼適合用訊息傳，但不包含「拉一杯花」作品集的照片。
  - 要連照片一起搬，請用存檔檔案。
- **備份**：iPhone 很久沒打開的網站資料可能會被系統清掉，建議偶爾匯出備份。
